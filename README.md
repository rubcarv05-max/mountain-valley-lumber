# Mountain Valley Lumber

Website for Mountain Valley Lumber: log homes, cabins and rough-cut lumber at 46231 Co Rd X, Saguache, Colorado.

**Live site:** https://rubcarv05-max.github.io/mountain-valley-lumber/

It's a static site (plain HTML, CSS and JavaScript) with no build step. Open `index.html` locally or let GitHub Pages serve it from `main`.

## Before launch
- Connect the contact form: replace `YOUR_FORM_ID` in `index.html` with a Formspree form ID.
- When the business's own domain is ready, replace the GitHub Pages URL in `index.html`, `robots.txt` and `sitemap.xml`.

Design tokens and the motion notes are in `DESIGN.md`.
